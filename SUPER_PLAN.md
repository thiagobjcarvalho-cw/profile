## Decisao de Arquitetura

### Opcao Escolhida: HTML Premium Unico

**Por que?**
- Carregamento rapido (sem build)
- Facil deploy
- Todo codigo em um arquivo
- Funciona em qualquer servidor

**Estrutura:**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- Meta, Fonts, Styles -->
</head>
<body>
  <!-- Navigation -->
  <!-- Hero -->
  <!-- About -->
  <!-- Experience -->
  <!-- Skills -->
  <!-- Projects -->
  <!-- Testimonials -->
  <!-- Contact -->
  <!-- Footer -->

  <script>
    // JavaScript inline
  </script>
</body>
</html>
```
