# 🚀 Portfólio Modular - Vue 3 + Vuetify

## 📁 Estrutura do Projeto

```
portfolio-vue/
├── index.html                 # Arquivo principal
├── src/
│   ├── main.js               # Configuração Vue + Vuetify
│   ├── components/           # Componentes modulares
│   │   ├── AppHeader.vue     # Header/Navigation
│   │   ├── HeroSection.vue   # Seção Hero
│   │   ├── AboutSection.vue  # Sobre mim
│   │   ├── ExperienceSection.vue # Timeline experiência
│   │   ├── SkillsSection.vue # Skills grid
│   │   ├── ProjectsSection.vue # Projetos
│   │   ├── TestimonialsSection.vue # Depoimentos
│   │   ├── ContactSection.vue # Contato
│   │   └── AppFooter.vue     # Footer
│   ├── composables/          # Lógica reutilizável
│   │   ├── useTheme.js       # Gerenciamento de tema
│   │   ├── useAnimations.js  # Animações
│   │   └── useIntersectionObserver.js # Scroll animations
│   ├── assets/
│   │   ├── styles/
│   │   │   ├── variables.scss # Variáveis CSS customizadas
│   │   │   └── animations.scss # Animações CSS
│   │   └── images/
│   └── data/
│       ├── experience.js     # Dados da experiência
│       ├── skills.js         # Dados das skills
│       ├── projects.js       # Dados dos projetos
│       └── testimonials.js   # Dados dos depoimentos
```

## 🎯 Vantagens da Modularização

- ✅ **Edição Rápida**: Modifique apenas o componente necessário
- ✅ **Performance**: Lazy loading de componentes
- ✅ **Manutenção**: Código organizado e fácil de entender
- ✅ **Escalabilidade**: Fácil adicionar novas seções
- ✅ **Reutilização**: Componentes podem ser reutilizados

## 🛠 Tecnologias

- **Vue 3** (Composition API + Script Setup)
- **Vuetify 3** (Material Design 3)
- **SCSS** para customizações
- **Vite** para build rápido
- **TypeScript** (opcional, mas recomendado)

## 🎨 Design System

- **Vuetify Theme** customizado com suas cores
- **Animações** suaves com CSS + JavaScript
- **Responsivo** mobile-first
- **Acessibilidade** seguindo padrões WCAG
- **Performance** otimizada com lazy loading
